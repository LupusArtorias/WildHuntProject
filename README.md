# Wild Hunt Project

## Overview

The Wild Hunt Project is a manifesto-driven initiative to create decentralized, open organizations where courageous, creative, and dedicated individuals unite to hunt down the world's problems. A Wild Hunt Knight exemplifies purposeful action, harnessing intelligence, wisdom, and collaboration to forge a brighter future for humanity. This repository contains the website for the Wild Hunt Project, which outlines its principles, framework, and call to action for those inspired to join the mission.

The website serves as a public-facing platform to share the project's vision, manifest, core foundations, and an introduction to its founder, a Venetian-Irish problem-hunter nicknamed "Wolf." It is built with HTML, CSS, and JavaScript, featuring a responsive design with light and dark mode support.

## Project Purpose

The Wild Hunt Project aims to:

- Unite individuals to tackle global challenges through decentralized collaboration.
- Promote ethical, legal, and moral problem-solving with a focus on the greater good.
- Inspire action through a clear manifesto and core foundations that guide Wild Hunt Knights in their mission to improve humankind.

As stated on the website:

"The Wild Hunt Project serves as a manifesto for creating decentralized, open organizations where courageous, creative, and dedicated individuals unite to hunt down the world's problems."

## Repository Structure

The repository contains the following key files and directories:

- index.html: The main webpage, including sections for About, Who Am I?, The Wild Hunt Manifest, Core Foundations, and Walk the Path.
- attributions.html: A page listing icon sources and credits.
- styles.css: Stylesheet for the website, including responsive design and light/dark mode themes.
- script.js: JavaScript file for dynamic functionality (e.g., theme toggling, name animation).
- images/: Directory containing logos, icons, and other assets used on the website.
- README.md: This file, providing an overview and setup instructions.

## The Wild Hunt Manifest

The manifest, as outlined in the index.html file, defines the principles that guide Wild Hunt Knights. These principles ensure that problem-hunting is conducted responsibly, ethically, and effectively:

- Purpose with Responsibility: Solutions must serve the greater good without causing unintended harm.
- Solutions Without Fear: Problem-hunting should uphold freedom and dignity, never creating fear or domination.
- Legality, Ethics, and Morality: Knights operate within the law, guided by a strong ethical and moral compass.
- Balanced Action: Solutions balance immediate needs with long-term impacts, avoiding extreme measures that create chaos.
- Humility Over Pride: Knights remain humble, prioritizing effective solutions over ego.
- Preservation of Freedom: Knights maintain personal independence, ensuring the mission does not restrict their lives.
- Zero Tolerance for Unethical Conduct: Any illegal, unethical, or immoral actions result in immediate expulsion from the project.
- Learn from History: Knights draw wisdom from past successes and failures to craft innovative solutions.

## Core Foundations

The project is built on three core foundations, each representing a pillar of the Wild Hunt approach:

Astutia - Collaboration and Community:

- Support and share solutions.
- Collaborate with diverse individuals.
- Build communities to address systemic challenges.


Ferocies - Protect and Act:

- Defend humanity from threats.
- Act decisively to help those impacted.
- Address root causes to protect the future.



Sapientes - Wisdom and Innovation:

- Invent creative, sustainable solutions.
- Innovate existing methods for modern problems.
- Continuously improve through knowledge and experimentation.

## Joining the Wild Hunt

Joining the Wild Hunt Project is open to anyone who resonates with its values. As described in the "Walk the Path" section:


- No formal process: There are no forms or gates; alignment with the purpose, manifest, and foundations is enough.



- Public or anonymous participation: You can associate publicly (e.g., via social media tags) or remain anonymous using a pseudonym.



- Dedication matters: Your intent to hunt problems and uphold the project's principles defines your role as a Knight.



"Brothers and Sisters of the Wild Hunt, see you on the path!"
